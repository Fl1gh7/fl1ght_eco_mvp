# Как прогнать ServiceFl1ght

Команды — из корня репозитория, с активированным venv. Ключи — в `.env` (в git его нет).

```bash
source venv/bin/activate          # Windows: venv\Scripts\activate
```

Без `YANDEX_API_KEY` / `YANDEX_FOLDER_ID` шаги с ИИ не поедут. Redis и токены VK/Telegram нужны только там, где явно написано.

---

## 1. Без ИИ и без сети

Покрывает слой данных, матчер прайса и сравнение секретов вебхуков:

```bash
python -m unittest tests.test_db_manager tests.test_matcher tests.test_webhook_auth
```

Ожидание: `OK`.

---

## 2. Вся воронка в консоли

```bash
python test_full_logic.py
```

Сито → прайс → Продавец → запись в `database.db`. Пишете как клиент, в консоли видно каждый слой. Выход: `выход` или Ctrl+C.

Сначала спам — Сито должно оборвать до Продавца:

```
купить продвижение в директ
```

Ожидание: `Отклонено`, trash.

Потом живой заказ (по одному сообщению):

```
Сломался экран на айфоне 13, сколько стоит замена?
```

Дальше по смыслу, но закрыть все шесть пунктов: модель (уже есть), поломка, явное согласие с ценой, адрес, **интервал** двух часов (`завтра с 14:00 до 16:00`, не «в 15:00»), телефон.

Ожидание: после первого сообщения — целевой лид и цены из прайса; пока чего-то не хватает — `ACTIVE`; когда всё собрано — `SUCCESS`.

«Дорого, подумаю» должно дать `DELAYED`, не SUCCESS. Цифра на экране 13 — из прайса, не случайная и не от Pro Max.

---

## 3. Только Продавец

Если шаг 2 уже ясен — можно пропустить. Сразу диалог с менеджером и прайсом, без Сита:

```bash
python seller_chat/test_closer.py
```

Тот же сценарий с шестью полями.

---

## 4. Скаут VK (нужны Redis и Celery)

```bash
python run_scout_now.py
```

Задача уходит в очередь. Через пару минут в [админке скаутов](https://admin.fl1ght.ru) появляются строки (VK, score, лид или мусор). Локально админка — `http://localhost:8000/crm`.

Если Task ID есть, а логов нет — не запущен worker:

```bash
celery -A core.celery_app worker --beat --concurrency=1 --loglevel=info
```

Beat сам гоняет скаута раз в два часа. `run_scout_now.py` — ручной прогон.

Кнопки «Ищейка» в админке тяжёлые: TG глушит радар и занимает RAM, VK **перезаписывает** список пабликов. На маленьком VPS без нужды их лучше не запускать.

---

## 5. Живые каналы

| Куда | Что проверить | Успех |
|---|---|---|
| [fl1ght.ru](https://fl1ght.ru) или `POST /api/chat` | Сценарий из шага 2 | Ответы ИИ, в конце заказ |
| Официальный Telegram-бот | Личка боту | То же. После SUCCESS — алерт в `TELEGRAM_CHAT_ID` |
| ЛС сообщества VK | Личка **группы** | То же. Первое спам-сообщение Сито может оборвать |
| Avito | Ничего | Заглушка. Вебхук всегда **501** |

В Telegram-боте Сита нет: первое сообщение сразу идёт Продавцу.

Карточки заказов: [crm.fl1ght.ru](https://crm.fl1ght.ru). Логи скаутов: [admin.fl1ght.ru](https://admin.fl1ght.ru). API заказов: `/api/crm/orders` (тот же Basic Auth).

---

## Если что-то падает

| Симптом | Куда смотреть |
|---|---|
| `Ключи Yandex не найдены` | `.env` в корне, запуск не из корня репозитория |
| unittest | `python core/database.py`, при пустом прайсе — `python import_excel.py` |
| Консоль молчит / ошибка ИИ | ключи Yandex, сеть |
| Скаут «отправил задачу», логов нет | Redis + Celery worker |
| Бот VK/TG молчит | `VK_CALLBACK_SECRET`, `TELEGRAM_WEBHOOK_SECRET`, вебхук на `https://admin.fl1ght.ru/api/...` |
| Avito 501 | так и задумано |
